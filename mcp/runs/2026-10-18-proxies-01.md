## Queue and contract cards

All calls use the shared authenticated HyperHive API client, with JSON bodies and no retries. Success is empty HTTP 200, mapped to {success:true}; no proxy IDs or state are invented. Failures expose HTTP status only. Read master/api/npmapi/proxy.go and master/npm/proxy.go; mcp/auth.go and master/api/login.go retain authentication boundaries.

| Tool | Mapping | Contract | State |
| --- | --- | --- | --- |
| create_proxy | POST /proxy/create | Full configuration; domains, scheme/host/port, flags, access-list/certificate IDs, metadata, advanced config and nested locations. Enabled and create ID are ignored by downstream helper and not writable through this operation. | verified |
| update_proxy | PUT /proxy/edit | Same full replacement configuration plus positive id; empty domains rejected before API. Managed proxy edits yield 403. No read/merge/write. | verified |
| enable_proxy | POST /proxy/enable | Positive id JSON body; backend permits managed proxies. | verified |
| disable_proxy | POST /proxy/disable | Positive id JSON body; managed proxies yield 403. | verified |
| setup_frontend_proxy | POST /proxy/setupFrontEnd | Required domain and nonnegative certificate id (0 means no TLS); creates or replaces managed proxy by domain; frontend 8079/API_PORT targets are server-owned. | verified |
| setup_secure_frontend_proxy | POST /proxy/setupFrontEndSecure | Required publicDomain/privateDomain and nonnegative publicCertificateId/privateCertificateId. Private then public write, no rollback; zero disables TLS for the relevant proxy. | verified |

All mutation annotations: readOnly=false, destructive=true (replacement/configuration can overwrite), idempotent=false conservatively; backend remains authoritative. Input errors must make no backend request. Known fields required for replacement protect omitted-vs-false/zero semantics. Unknown fields rejected, arbitrary metadata preserved.
