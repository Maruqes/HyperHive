# MCP VM ISO removal increment

## Scope and contract

User explicitly requested adding the previously discussed endpoint to MCP.
Target: one new tool, remove_vm_isos. Prior deletion exclusion overridden only
for POST /virsh/removeiso/{vm_name}; ISO files are retained. High risk,
per-invocation approval, private prior settings and secure domain XML before write.
No body; plain-text HTTP 200 maps to accepted:true. All CD-ROM devices and
CD-ROM boot entries removed; live detach can fail partially before persistent
XML redefinition. No rollback, automatic retry or completion fields invented.
Sources: master/api/virsh.go removeIso, master/services/virsh.go RemoveIso,
slave/virsh/common.go RemoveIsoFromVM.

## Validation

Baseline: full MCP tests passed (643 tests). Red contract fixture failed with
unknown tool before implementation. New fixture reuses existing modern/legacy
HTTP and executable stdio harness to verify auth, path/body, approval denial and
cancellation, snapshot failure, retained prior state, success and safe backend
failure without retry. Dedicated both-transport tests cover discovery, invalid
arguments, missing picker, secure snapshot failure and persistence failure.
Final full normal suite: 654 passed across five packages. Final vet passed.
Final full race suite: 654 passed across five packages. git diff --check passed.
Completed: 1/1 new tools. No real VM operation or production deployment.
