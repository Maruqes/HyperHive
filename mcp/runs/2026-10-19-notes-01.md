## Queue and contract cards
1. `list_notes`: GET /notes/. No inputs. Returns the database array ordered by descending ID, including empty []. Read-only, idempotent, non-destructive. Source: listNotes, GetAllNotes.
2. `get_note`: GET /notes/{id}. Positive integer id; no request body. Returns {id,titulo,nota}; missing note HTTP 404. Read-only, idempotent, non-destructive. Source: getNote, noteIDFromRequest, GetNoteByID.
3. `create_note`: POST /notes/. Required nonblank strings titulo and nota, sent unchanged as JSON. Returns created note HTTP 201. Creates one row; no retries; non-idempotent, non-destructive. Source: createNote, decodeNoteRequest, AddNote.
4. `replace_note`: PUT /notes/{id}. Positive integer id and both required nonblank strings. Full replacement of title/body; no merge/defaulting. Returns updated note HTTP 200, 404 when missing. Idempotent replacement; overwrites existing values. Source: editNote, UpdateNoteByID.
5. `patch_note`: PATCH /notes/{id}. Same complete replacement contract as PUT, explicitly named operation with fixed method. Both fields required. Same output/failure/side effects as replace_note.
