- List preserves fleet/storage/reset and partial-error fields; health preserves diagnostic HTTP 503 with healthy=false. Invalid shapes are rejected without leaking bodies.
- Create validates name, unique nonempty server list and optional port pair; omitted ports allocate automatically. HyperHive owns inventory, uniqueness and reservations.
- Start/stop/delete use a required bounded fleet ID and exact bodyless method/path; preserve queued JSON HTTP 202, never claim completion or retry. Delete alone is destructive and explicitly authorized; offline nodes can delay cleanup.
- Credentials explicitly returns scoped secrets and rejects deleting fleets; other tools never fetch credentials.
